Accessibility Fixes (WAVE Evaluation Results)

* **Fixed low-contrast text on project pages:** Resolved WAVE contrast errors by changing the white description text inside layout cards to high-contrast dark charcoal (#1a1a1a).
* **Added semantic form structures:** Programmed explicit relationships into the Contact page form by binding unput fields directly to labels using matching 'id' and 'for' attributes.
* **Organized interactive data controls:** Built a clean structural layout by grouping the contact inputs cleanly inside a sematic '<fieldset>' container with a clear '<legend>'.

Visual Disign & Gestalt Principles Applied
